# Conso Downloader

**Téléchargez vos données Enedis en un clic.**

## 🚀 À quoi sert cette extension ?

Le site d’Enedis ne permet pas de récupérer facilement vos données historiques, en particulier votre consommation par demi-heure : il faut le faire **semaine par semaine**, ce qui est très pénible.

**Conso Downloader** ajoute simplement une fonctionnalité manquante : un bouton pour **télécharger tout votre historique de consommation en une seule fois**, au format CSV.

## ⚙️ Comment l'utiliser

1. Installez l’extension depuis le Chrome Web Store **(en attente de validation)**.
2. Rendez-vous sur votre espace client Enedis, dans la section [Suivre ma consommation](https://mon-compte-particulier.enedis.fr/visualiser-vos-mesures-consommation)
3. Un **nouveau bouton gris** apparaît en bas à gauche de la page avec le texte **Télécharger tout mon historique**.
4. Sélectionnez l’option **Heures**, puis cliquez sur **Visualiser** pour afficher vos données horaires.
5. Une fois les données horaires affichées, le bouton devient **bleu** et cliquable
6. Cliquez dessus, patientez quelques secondes, **votre fichier CSV** contenant tout votre historique sera téléchargé automatiquement.

## 🧩 Détails techniques

- Le fichier téléchargé est au format **CSV**, compatible avec Excel, LibreOffice, Google Sheets, etc.
- L’extension n’envoie **aucune donnée à un service externe** : tout se passe directement dans votre navigateur.

_Conso Downloader n’est pas affiliée à Enedis_
_C’est un outil libre et indépendant destiné à simplifier l’accès à vos propres données._

_Cette extension existe uniquement parce qu’il n'existe aujourd'hui aucun moyen récupérer l’intégralité de ses données auprès d’Enedis, y compris via demande écrite, en dépit des obligations prévues par le RGPD._
